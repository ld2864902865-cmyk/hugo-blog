> **本章核心目标**：真实物理世界（连杆、电机）是**连续的**，但你的控制器最终要跑在**单片机 / 电脑（离散时间，每隔 $T_s$ 算一次）**里。本章用最短路径打通 $s$ 域到 $z$ 域的直觉，不手算复杂反变换。

---

## 1. 为什么要有 Z 变换？

在连续时间里，我们用拉氏变换把微分方程变成关于 $s$ 的代数方程；在数字计算机里，信号是一串按固定采样周期 $T_s$ 采出来的数列 $x[0], x[1], x[2], \dots, x[k]$，系统方程是**差分方程**。

Z 变换就是**离散世界的拉氏变换**：

$$X(z) = \mathcal{Z}\{x[k]\} = \sum_{k=0}^{\infty} x[k]\,z^{-k}$$

其中最核心的物理符号就是 **$z^{-1}$**：
- **$z^{-1}$ 的唯一含义：延迟一个采样周期 $T_s$**（即把现在的 $x[k]$ 变成上一拍的 $x[k-1]$）。
- 在 Simulink 里，它就是 `Unit Delay` 模块；在 C 语言里，它就是一个保存上一次值的变量 `x_prev`！

---

## 2. $s$ 平面到 $z$ 平面的映射（最重要的几何直觉）

拉氏变换与 Z 变换之间有一条黄金桥梁：

$$z = e^{s T_s} = e^{(\sigma + j\omega)T_s} = \underbrace{e^{\sigma T_s}}_{\text{模长 } |z|} \cdot \underbrace{e^{j\omega T_s}}_{\text{相角 } \angle z}$$

由这条公式，立刻得出**离散系统的稳定性铁律**：

| 连续系统（$s$ 平面） | 映射关系 $z = e^{sT_s}$ | 离散系统（$z$ 平面） |
| --- | --- | --- |
| **左半平面** ($\sigma < 0$，稳定) | $|z| = e^{\sigma T_s} < 1$ | **单位圆内部** ($|z| < 1$，稳定！) |
| **虚轴** ($\sigma = 0$，临界稳定) | $|z| = 1$ | **单位圆上** ($|z| = 1$，等幅振荡) |
| **右半平面** ($\sigma > 0$，发散) | $|z| > 1$ | **单位圆外部** ($|z| > 1$，发散爆炸) |
| **原点** ($s = 0$，积分器) | $z = e^0 = 1$ | **$z = 1$ 点**（离散积分器 $\frac{T_s}{z-1}$） |

> **一句话记忆**：连续系统看极点是不是都在**左边**（$\text{Re}(s) < 0$）；离散系统看极点是不是都在**圆内**（$|z| < 1$）。离原点越近，衰减越快！

---

## 3. 采样周期 $T_s$ 怎么选？（工程核心参数）

采样周期 $T_s$（或采样频率 $f_s = 1/T_s$）不是随便拍脑袋的：
- **理论底线（香农采样定理）**：$f_s > 2 f_{\max}$，否则会发生频谱混叠（高频假冒成低频）。
- **控制工程经验法则**：取**闭环带宽 $f_b$ 的 $10 \sim 20$ 倍**（或者保证一个上升时间内至少采 $10 \sim 20$ 个点）。
  - 例：单连杆/二连杆机械臂闭环带宽约 $5 \sim 10\text{ Hz}$ → 控制周期选 $f_s = 200\text{ Hz} \sim 1000\text{ Hz}$（即 $T_s = 1\text{ ms} \sim 5\text{ ms}$）非常充裕。
- **采样太慢的危害**：数字控制自带一个**零阶保持器（ZOH）**（把这一拍算出的力矩保持住，直到下一拍更新），它近似等效于一个 **$\frac{T_s}{2}$ 的纯时间延迟**！$T_s$ 太大就会吃光你的相位裕度，把原本稳定的连续控制器搞震荡。

## 4. 怎么把连续控制器变成离散代码？（常用离散化方法）

设计好连续控制器 $C(s)$ 后，怎么转成 $C(z)$ 放进单片机或 Simulink 离散模块？

| 离散化方法 | $s \to z$ 替换公式 | 特点与适用场景 | MATLAB `c2d` 选项 |
| --- | --- | --- | --- |
| **后向欧拉（Backward Euler）** | $s \approx \dfrac{1 - z^{-1}}{T_s}$ | 绝对保持稳定、最容易手写代码（离散 PID 最常用） | — |
| **双线性变换（Tustin / 梯形法）** | $s \approx \dfrac{2}{T_s}\dfrac{1 - z^{-1}}{1 + z^{-1}}$ | **精度最高、完美保稳定**，频域畸变小，控制器离散化首选 | `c2d(C, Ts, 'tustin')` |
| **零阶保持（ZOH）** | 精确脉冲响应匹配 | **被控对象（Plant）离散化首选**（因为 DAC 就是零阶保持） | `c2d(P, Ts, 'zoh')` |

### 4.1 离散 PID 写成代码长什么样？（位置式 PID）

设采样周期为 $T_s$，当前第 $k$ 拍误差为 $e[k]$：
- **比例项**：$u_p[k] = K_p \cdot e[k]$
- **积分项**（累加求和）：$I[k] = I[k-1] + K_i \cdot T_s \cdot e[k]$（别忘了对 $I[k]$ 做限幅抗饱和！）
- **微分项**（差分求导，建议加一阶低通滤波）：$u_d[k] = K_d \cdot \dfrac{e[k] - e[k-1]}{T_s}$
- **总输出**：$u[k] = \text{clamp}(u_p[k] + I[k] + u_d[k],\ u_{\min},\ u_{\max})$

## 5. MATLAB 与 Simulink 实操

### 5.1 MATLAB 一行离散化与对比

```matlab
s = tf('s');
J = 0.05; b = 0.1;
P = 1 / (J*s^2 + b*s);
C = pid(20, 15, 3, 1/50);   % 连续 PID（带滤波时间常数 Tf=1/50）

Ts = 0.01;                  % 100 Hz 控制周期（10 ms）
Pd = c2d(P, Ts, 'zoh');     % 对象用 ZOH 离散化
Cd = c2d(C, Ts, 'tustin');  % 控制器用 Tustin 离散化

% 对比连续闭环 vs 离散闭环的阶跃响应
T_cont = feedback(C * P, 1);
T_disc = feedback(Cd * Pd, 1);

figure;
step(T_cont, 'b-', T_disc, 'r--');
grid on; legend('连续控制', '离散控制 (Ts=10ms)');
% 试着把 Ts 改成 0.1s (10Hz)，你会亲眼看到采样太慢如何让系统剧烈震荡甚至发散！
```

### 5.2 Simulink 里的「混合仿真」（最贴近真实硬件）
真实世界是**连续对象 + 离散控制器**：
- **被控对象（单连杆/二连杆）**：继续用连续的 `Integrator`。
- **控制器**：把 `PID Controller` 模块的 `Time domain` 从 `Continuous-time` 改成 `Discrete-time`，填上 `Sample time = Ts`（如 `0.005`）。Simulink 会自动在接口处处理采样与零阶保持，直接验证你的控制频率够不够用！
