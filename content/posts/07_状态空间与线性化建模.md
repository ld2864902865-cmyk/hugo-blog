> **本章核心目标**：理解为什么二连杆需要「现代控制」，掌握**状态空间建模**和**非线性系统雅可比线性化**，为下一章 LQR 控制器设计铺平道路。

---

## 1. 为什么经典控制（传递函数）遇到二连杆就吃力了？

经典控制（传函 / Bode / PID）非常适合**单输入单输出（SISO）线性系统**，但二连杆（2-DOF 机械臂 / 双摆）天然带着三大难题：

| 难题 | 二连杆里的具体表现 | 传递函数的局限 | 状态空间的优势 |
| --- | --- | --- | --- |
| **多变量强耦合（MIMO）** | 关节 1 转动会产生惯性耦合和科氏力，把关节 2 甩歪 | 只能写成复杂的传递函数矩阵，Bode 图/根轨迹几乎没法用 | 用矩阵 $\mathbf{A}, \mathbf{B}$ 天然统一描述任意多输入多输出 |
| **强非线性** | 含 $\sin\theta_1, \cos(\theta_1-\theta_2), \dot{\theta}_1\dot{\theta}_2$ | 无法直接写全局传递函数 | 可直接写成 $\dot{\mathbf{x}} = f(\mathbf{x}, \mathbf{u})$，并在工作点一键线性化 |
| **需要内部状态信息** | 既关心角度 $\theta_1,\theta_2$，又关心角速度 $\dot{\theta}_1,\dot{\theta}_2$ | 只看输入输出黑盒，丢失内部状态和初始条件 | 直接刻画全部内部状态，天然支持初始条件和全状态反馈 |

## 2. 状态空间方程的核心直觉

线性定常（LTI）状态空间的标准写法：

$$\begin{cases}
\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u} & \text{（状态方程：描述系统内部怎么演化）} \\
\mathbf{y} = C\mathbf{x} + D\mathbf{u} & \text{（输出方程：描述传感器能测到什么）}
\end{cases}$$

- **状态向量 $\mathbf{x} \in \mathbb{R}^n$**：能**完整描述系统此刻储能与运动状态**的最少变量集合。对于机械系统，**广义位置 + 广义速度**就是最自然的状态变量！
  - 单连杆（2 阶）：$\mathbf{x} = [\theta,\ \dot{\theta}]^T$
  - 二连杆（4 阶）：$\mathbf{x} = [\theta_1,\ \theta_2,\ \dot{\theta}_1,\ \dot{\theta}_2]^T$
- **输入向量 $\mathbf{u} \in \mathbb{R}^m$**：控制器输出的力/力矩（二连杆双驱为 $[\tau_1, \tau_2]^T$；欠驱动双摆为 $[\tau_1]$）。
- **矩阵 $A$**：系统内部动力学（**$A$ 的特征值 `eig(A)` 就是传递函数的极点！** 这一句话瞬间打通经典控制与现代控制）。
- **矩阵 $B$**：控制输入如何「撬动」各个状态。
- **矩阵 $C$**：传感器观测矩阵（比如只有角度编码器没有测速机，就只能测 $\theta_1, \theta_2$）。

> **经典控制 vs 现代控制稳定性统一**：
> 传函极点全在左半平面 $\Longleftrightarrow$ 矩阵 $A$ 的所有特征值实部全部 $< 0$（`all(real(eig(A)) < 0)`）。

## 3. 二连杆动力学方程标准形式（机器人学的基石）

通过拉格朗日方程（$L = T - V$，动能减势能），任何刚体多连杆机械臂（包括二连杆）的动力学最终都长成这个极其优美的标准矩阵形式：

$$M(\mathbf{q})\ddot{\mathbf{q}} + C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} + G(\mathbf{q}) = \boldsymbol{\tau}$$

| 矩阵/向量 | 物理含义 | 在二连杆里的直观感受 |
| --- | --- | --- |
| $\mathbf{q} = [\theta_1, \theta_2]^T$ | 关节角度向量 | 机械臂当前的姿态 |
| $M(\mathbf{q})$（$2\times 2$ 对称正定） | **质量/惯量矩阵** | 对角元是各自转动惯量，**非对角元 $M_{12}$ 就是两关节间的加速度耦合**（且随姿态 $\theta_2$ 变化！） |
| $C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}}$ | **离心力与科氏力项** | 甩得越快越明显（与 $\dot{\theta}^2, \dot{\theta}_1\dot{\theta}_2$ 成正比） |
| $G(\mathbf{q})$ | **重力矩向量** | 含 $\sin\theta_1, \sin(\theta_1+\theta_2)$，静止悬停时的主要负载 |
| $\boldsymbol{\tau} = [\tau_1, \tau_2]^T$ | **电机关节力矩** | 你的控制器要算出来的量 |

**如何写成非线性状态方程 $\dot{\mathbf{x}} = f(\mathbf{x}, \mathbf{u})$ 放进 Simulink？**
直接左乘 $M(\mathbf{q})^{-1}$ 解出加速度 $\ddot{\mathbf{q}}$：

$$\ddot{\mathbf{q}} = M(\mathbf{q})^{-1}\Big(\boldsymbol{\tau} - C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} - G(\mathbf{q})\Big)$$

在 Simulink 里，把上面这行写进一个 `MATLAB Function` 模块，输出 $\ddot{\mathbf{q}}$，后面接两个向量 `Integrator`（分别得到 $\dot{\mathbf{q}}$ 和 $\mathbf{q}$），再反馈回输入——**你的二连杆高精度非线性仿真对象就建好了！**

## 4. 非线性系统在平衡点线性化（雅可比矩阵）

为了把现代控制里的 **LQR** 用在二连杆上，我们需要在目标平衡点 $(\mathbf{x}_e, \mathbf{u}_e)$ 附近（满足 $f(\mathbf{x}_e, \mathbf{u}_e) = \mathbf{0}$）做一阶泰勒展开，求局部线性模型：

$$\Delta\dot{\mathbf{x}} \approx A\,\Delta\mathbf{x} + B\,\Delta\mathbf{u}$$

其中：

$$A = \left.\frac{\partial f(\mathbf{x}, \mathbf{u})}{\partial \mathbf{x}}\right|_{(\mathbf{x}_e, \mathbf{u}_e)}, \qquad B = \left.\frac{\partial f(\mathbf{x}, \mathbf{u})}{\partial \mathbf{u}}\right|_{(\mathbf{x}_e, \mathbf{u}_e)}$$

> **例子（单连杆在竖直向上倒立点 $\theta_e = \pi, \dot{\theta}_e = 0, u_e = 0$ 线性化）**：
> 原非线性方程：$\dot{x}_1 = x_2$，$\dot{x}_2 = \frac{1}{J}(u - b x_2 - mgl\sin x_1)$。
> 因为在 $x_1 = \pi$ 处 $\frac{\partial \sin x_1}{\partial x_1} = \cos\pi = -1$，立即得到：
> $$A = \begin{bmatrix} 0 & 1 \\ \dfrac{mgl}{J} & -\dfrac{b}{J} \end{bmatrix}, \qquad B = \begin{bmatrix} 0 \\ \dfrac{1}{J} \end{bmatrix}$$
> 看左下角 $+\frac{mgl}{J} > 0$：算 `eig(A)` 会发现有一个**正实部特征值**（右半平面极点），这正是「倒立摆不控就会倒」的数学体现！

## 5. MATLAB 实操：用符号工具箱自动求雅可比线性化（告别手算求导）

对于二连杆，手算 $4\times 4$ 雅可比矩阵非常容易算错，工程里**一律用 MATLAB `jacobian` 自动生成**：

```matlab
%% 以单连杆为例演示「自动求雅可比线性化」通用模板（二连杆完全同理，只需把 x 扩成 4 维）
syms theta dtheta u real
syms J b m l g real

x = [theta; dtheta];
f = [dtheta;
     (u - b*dtheta - m*g*l*sin(theta)) / J];

% 1. 一行代码求符号雅可比矩阵
A_sym = jacobian(f, x);
B_sym = jacobian(f, u);

% 2. 代入平衡点（例如水平悬停点 theta_e = pi/2, dtheta_e = 0, u_e = m*g*l）
%    或者倒立点（theta_e = pi, dtheta_e = 0, u_e = 0）
params_sym = [J,    b,   m,   l,    g,    theta, dtheta, u];
params_val = [0.05, 0.1, 1.0, 0.25, 9.81, pi,    0,      0];

A = double(subs(A_sym, params_sym, params_val))
B = double(subs(B_sym, params_sym, params_val))

% 3. 检查开环特征值（极点）
disp('倒立点开环特征值（应有一个正根，表示不稳定）：');
eig(A)
```

> **提示**：如果你已经在 Simulink 里搭好了非线性二连杆模型，甚至连符号求导都省了——直接用 MATLAB 的 `linearize`（Simulink Control Design）或 `linmod` 命令，就能在指定工作点直接提取出 $(A, B, C, D)$ 矩阵！
